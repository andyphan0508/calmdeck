Security

Last updated: November 2026

Calmdeck works on your Mac, your passwords and your servers, so it has to earn your trust. This page explains what stays on your Mac, what is sent and where, and what Calmdeck checks before it changes anything.

What stays on your Mac

  • Calmdeck has no analytics, no telemetry and no account. It does not report what you scan, clean or connect to.
  • Your files, scan results, server list, workspaces and activity log are kept only on your Mac. The activity log can be read only by your user account.
  • Secret values found by Secrets Scan never leave your Mac and are never saved. On screen they are shown masked, for example ghp_…x9.

What Calmdeck sends, and when

Calmdeck itself connects to the internet on its own in only these cases:

  • Update check, at most once a day: it asks GitHub for the latest version and downloads a small public settings file from this website. Nothing about you or your Mac is sent. You can turn this off in Settings.
  • License check, only if you have bought Pro, at most once every three days: your license key is checked with Lemon Squeezy, our payment provider. When you activate a license, Lemon Squeezy also receives your Mac's name so you can recognise it in your purchase account.
  • Uptime checks you create: Calmdeck checks only the addresses you add, on the schedule you set.

Everything else (connecting to a server, a cluster, GitHub or GitLab) happens only when you use that feature. Your licence is tied to an anonymous code derived from your Mac; your Mac's hardware ID is never sent.

Passwords and tokens

  • Saved SSH passwords and access tokens are stored in the macOS Keychain, not in ordinary files.
  • While Calmdeck signs in to a server with a password, the password sits briefly in a temporary file that only your account can read, and the file is deleted as soon as the sign-in finishes. It is never placed in a command line where other programs could see it.
  • When a task needs administrator rights, macOS asks for your password in its own window. Calmdeck never sees your Mac's administrator password.
  • Calmdeck never reads your GitHub CLI token, and never changes your Kubernetes config files.

Before anything changes

  • Server and cluster actions show you the exact command that will run before you confirm it. Names and paths are checked and safely quoted, so a strange file or service name cannot turn into a different command.
  • Cleanup never deletes key system or home folders, such as your home folder itself, Documents or the system Library, and it removes shortcuts (symbolic links) without following them to the files they point to.
  • During cleanup, administrator rights are requested only for items outside your home folder, only after a normal delete has failed, and only if you allow it in Settings.
  • When Touch ID confirmation is on (it is by default), Calmdeck asks for it every time before sensitive actions such as deleting permanently, using a saved server password or revealing a cluster secret.
  • Scanning or opening a project does not run code from it. If a project's git settings could start other programs, Calmdeck does not run git there until you choose to trust that project.
  • Cleanups, administrator commands, and server and cluster actions are written to a local activity log, so you can see what happened and when.

Servers

  • The first time you connect to a server, Calmdeck remembers its identity. If that identity later changes, the connection is refused, which protects you from someone impersonating your server.
  • Port forwards are open only to your own Mac unless you choose to share them with your network.
  • Calmdeck installs nothing on your servers, and it does not read project folders on a server that belong to another account.

Updates

  • Updates are downloaded only from GitHub over a secure connection.
  • Before replacing the app, Calmdeck checks that the new copy is signed by Calmdeck's own Apple developer team and that it is genuinely newer than the version you have. If anything fails, your current copy is kept.

What Calmdeck cannot be made to do

  • Websites and other apps cannot send commands to Calmdeck: it has no web link handler and no scripting interface.
  • Calmdeck is signed by our Apple developer team with macOS runtime protection turned on, which stops other programs from injecting code into it.
  • Send Feedback never sends anything by itself. It opens your mail app or GitHub with a short summary (app version, macOS version, language, settings) that you can read before sending. It contains no file paths and no user name.

Why Calmdeck needs broad access

Calmdeck is not limited to the App Store sandbox, because cleaning developer caches, managing ports and connecting over SSH require reaching files and tools across your Mac. If you grant Full Disk Access, Calmdeck uses it to measure and clean folders such as caches and Xcode data and to read security settings. You can remove that access at any time in System Settings, Privacy & Security; the parts that need it will then show what is missing.

Good to know

  • The Home page runs developer tools you already have, such as Homebrew, to check their health. Those tools may contact their own servers according to their own settings.
  • Commands you type into a console, and automatic fixes you set up for uptime checks, run as you wrote them.
  • The very first connection to a new server is trusted as described above; check its fingerprint with your host if it matters to you.

Report a security issue

If you find a problem, please tell us privately using the Contact link in the footer of the home page. We will reply, fix it, and credit you in the changelog if you wish.

Bảo mật

Cập nhật: Tháng 11/2026

Calmdeck làm việc với máy Mac, mật khẩu và máy chủ của bạn, nên phải xứng đáng với sự tin tưởng đó. Trang này nói rõ dữ liệu nào ở lại trên máy, dữ liệu nào được gửi đi và gửi tới đâu, và Calmdeck kiểm tra những gì trước khi thay đổi bất cứ thứ gì.

Những gì ở lại trên máy Mac

  • Calmdeck không có analytics, không telemetry, không cần tài khoản. Ứng dụng không báo cáo bạn quét, dọn hay kết nối tới đâu.
  • Tệp, kết quả quét, danh sách máy chủ, workspace và nhật ký hoạt động chỉ nằm trên máy của bạn. Nhật ký hoạt động chỉ tài khoản của bạn đọc được.
  • Giá trị bí mật do Quét bí mật tìm thấy không bao giờ rời máy và không được lưu lại. Trên màn hình chúng chỉ hiện dạng che, ví dụ ghp_…x9.

Calmdeck gửi gì, khi nào

Bản thân Calmdeck chỉ tự kết nối Internet trong các trường hợp sau:

  • Kiểm tra cập nhật, tối đa mỗi ngày một lần: hỏi GitHub phiên bản mới nhất và tải một tệp cài đặt công khai nhỏ từ website này. Không có thông tin nào về bạn hay máy Mac được gửi đi. Bạn có thể tắt việc này trong Cài đặt.
  • Xác minh bản quyền, chỉ khi bạn đã mua Pro, tối đa ba ngày một lần: mã bản quyền được kiểm tra với Lemon Squeezy, đơn vị thanh toán của chúng tôi. Khi kích hoạt, Lemon Squeezy nhận thêm tên máy Mac để bạn nhận ra máy trong tài khoản mua hàng.
  • Kiểm tra hoạt động do bạn tạo: Calmdeck chỉ kiểm tra các địa chỉ bạn thêm, theo lịch bạn đặt.

Mọi kết nối khác (tới máy chủ, cụm Kubernetes, GitHub hay GitLab) chỉ diễn ra khi bạn dùng tính năng đó. Bản quyền gắn với một mã ẩn danh tính từ máy Mac; mã phần cứng của máy không bao giờ được gửi đi.

Mật khẩu và token

  • Mật khẩu SSH và token truy cập đã lưu nằm trong Keychain của macOS, không nằm trong tệp thường.
  • Khi Calmdeck đăng nhập máy chủ bằng mật khẩu, mật khẩu chỉ nằm thoáng qua trong một tệp tạm mà chỉ tài khoản của bạn đọc được, và tệp bị xoá ngay khi đăng nhập xong. Mật khẩu không bao giờ nằm trong dòng lệnh, nơi chương trình khác có thể thấy.
  • Khi cần quyền quản trị, macOS hỏi mật khẩu trong cửa sổ của chính hệ thống. Calmdeck không bao giờ thấy mật khẩu quản trị của máy Mac.
  • Calmdeck không đọc token của GitHub CLI và không sửa tệp cấu hình Kubernetes của bạn.

Trước mỗi thay đổi

  • Thao tác trên máy chủ và cụm Kubernetes hiện đúng nguyên văn lệnh sẽ chạy trước khi bạn xác nhận. Tên và đường dẫn được kiểm tra và đặt trong dấu nháy an toàn, nên một tên tệp hay tên dịch vụ lạ không thể biến thành lệnh khác.
  • Khi dọn dẹp, Calmdeck không bao giờ xoá các thư mục hệ thống hay thư mục cá nhân quan trọng, như chính thư mục home, Documents hay Library của hệ thống. Lối tắt (symbolic link) bị xoá như một lối tắt, không đi theo tới tệp mà nó trỏ đến.
  • Khi dọn dẹp, quyền quản trị chỉ được xin cho mục nằm ngoài thư mục home, chỉ sau khi xoá thường thất bại, và chỉ khi bạn cho phép trong Cài đặt.
  • Khi bật xác nhận bằng Touch ID (mặc định bật), Calmdeck hỏi mỗi lần trước các thao tác nhạy cảm như xoá vĩnh viễn, dùng mật khẩu máy chủ đã lưu hay xem secret của cụm Kubernetes.
  • Quét hay mở một dự án không chạy mã nằm trong đó. Nếu cấu hình git của dự án có thể khởi chạy chương trình khác, Calmdeck không chạy git ở đó cho tới khi bạn chọn tin cậy dự án.
  • Các lần dọn dẹp, lệnh quản trị, thao tác trên máy chủ và cụm Kubernetes được ghi vào nhật ký hoạt động trên máy, để bạn xem lại đã xảy ra gì và khi nào.

Máy chủ

  • Lần đầu kết nối, Calmdeck ghi nhớ danh tính của máy chủ. Nếu danh tính đó thay đổi về sau, kết nối bị từ chối, giúp bạn tránh kẻ giả mạo máy chủ.
  • Chuyển tiếp cổng chỉ mở cho chính máy Mac của bạn, trừ khi bạn chọn chia sẻ cho mạng nội bộ.
  • Calmdeck không cài gì lên máy chủ, và không đọc thư mục dự án trên máy chủ thuộc về tài khoản khác.

Cập nhật

  • Bản cập nhật chỉ được tải từ GitHub qua kết nối bảo mật.
  • Trước khi thay ứng dụng, Calmdeck kiểm tra bản mới được ký bởi chính đội phát triển Apple của Calmdeck và thật sự mới hơn bản bạn đang dùng. Có bất kỳ lỗi nào, bản hiện tại được giữ nguyên.

Những điều không thể bắt Calmdeck làm

  • Website và ứng dụng khác không gửi lệnh được cho Calmdeck: ứng dụng không có trình mở liên kết web và không có giao diện điều khiển bằng script.
  • Calmdeck được ký bởi đội phát triển Apple của chúng tôi và bật lớp bảo vệ khi chạy của macOS, ngăn chương trình khác chèn mã vào ứng dụng.
  • Gửi phản hồi không tự gửi gì. Ứng dụng mở trình mail hoặc GitHub kèm bản tóm tắt ngắn (phiên bản app, phiên bản macOS, ngôn ngữ, cài đặt) để bạn đọc trước khi gửi. Bản tóm tắt không chứa đường dẫn tệp hay tên người dùng.

Vì sao Calmdeck cần quyền truy cập rộng

Calmdeck không bị giới hạn trong sandbox của App Store, vì dọn bộ nhớ đệm của công cụ lập trình, quản lý cổng và kết nối SSH đều cần truy cập tệp và công cụ trên khắp máy. Nếu bạn cấp Full Disk Access, Calmdeck dùng quyền này để đo và dọn các thư mục như bộ nhớ đệm, dữ liệu Xcode, và để đọc các thiết lập bảo mật. Bạn có thể gỡ quyền bất cứ lúc nào trong Cài đặt hệ thống, mục Quyền riêng tư & Bảo mật; các phần cần quyền đó sẽ báo rõ còn thiếu gì.

Nên biết

  • Trang Tổng quan chạy các công cụ lập trình bạn đã cài, như Homebrew, để kiểm tra tình trạng. Các công cụ đó có thể tự kết nối máy chủ của chúng theo cài đặt riêng.
  • Lệnh bạn tự gõ trong console, và cách khắc phục tự động bạn đặt cho kiểm tra hoạt động, chạy đúng như bạn viết.
  • Lần kết nối đầu tiên tới một máy chủ mới được tin tưởng như mô tả ở trên; nếu cần chắc chắn, hãy đối chiếu dấu vân tay khoá với nhà cung cấp máy chủ.

Báo lỗi bảo mật

Nếu bạn phát hiện vấn đề, hãy báo riêng cho chúng tôi qua liên kết Liên hệ ở chân trang chủ. Chúng tôi sẽ phản hồi, sửa lỗi và ghi công bạn trong changelog nếu bạn muốn.
